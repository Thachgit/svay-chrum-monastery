# Svay Chrum Monastery — Angular Frontend

Modern institutional website concept for Svay Chrum Monastery.

## Included
- Angular standalone application and routing
- Responsive homepage inspired by modern university/institutional websites
- Brand palette sampled approximately from the supplied monastery logo
- Khmer-first navigation and content
- About, Leadership, News, Events, Gallery, Education and Contact route placeholders
- Official social and map links supplied for the monastery
- Sample editorial cards and gallery sections

## Requirements
- Node.js 20.19+ or 22.12+
- npm

## Run locally
```bash
npm install
npm start
```
Open http://localhost:4200

## Production build
```bash
npm run build
```

## Logo
The supplied logo is stored at `public/images/svay-chrum-logo.png`.
Replace or update this file if a higher-resolution transparent version becomes available.

## Important notes
- This is a frontend prototype. News, events, leadership and gallery content are currently sample placeholders.
- The language button is a UI demonstration; full Khmer/English translation state is a later task.
- No backend or database is connected yet.
- Replace remote sample photography with official monastery photographs before publishing.
- Social links and the map link are based on the details provided for this project.
